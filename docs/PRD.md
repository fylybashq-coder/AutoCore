# AutoCore - Product Requirements

## Vision

AutoCore is a modern Dealer Management System (DMS) built for automotive dealerships and service centers.

## Goals

- Fast
- Simple
- Mobile First
- AI Powered

## Modules

- Dashboard
- Customers
- Vehicles
- Appointments
- Workshop
- Helpdesk
- Inventory
- Reports
- Users & Permissions

## Core Principles

- Less clicks
- Fast search
- Modern UI
- Real-time updates
